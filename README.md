# 임동우 이력서 웹페이지

HTML과 CSS로 만든 정적 이력서 페이지입니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 이력서 내용과 페이지 구조 |
| `style.css` | 반응형 레이아웃과 시각 스타일 |
| `profile.jpg` | 증명사진 |

`index.html`에서 경력, 학력, 기술, 활동, 자기소개 내용을 수정할 수 있습니다. `style.css`에서 색상과 배치를 조정할 수 있습니다.

페이지에는 연락처 정보가 포함되어 있습니다. 공개 배포 전에 연락처와 개인정보가 노출되어도 되는지 확인하세요.
